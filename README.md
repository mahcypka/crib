# Криббедж

Офлайн-игра в криббедж на Android: вы против компьютера, три уровня сложности, чёрный фон.
Интернет не нужен — приложение не запрашивает ни одного разрешения, включая доступ в сеть.

## Что внутри

- **Полные правила** American Cribbage Congress: сдача 6 карт, к crib, стартовая карта,
  розыгрыш до 31 со счётом вслух, «го», подсчёт по 15, парам, сериям, флешам и нобсу.
- **Три уровня сложности.** Компьютер видит только свои карты и открытые на столе —
  ваши карты ему недоступны технически, а не только по правилам.
- **Выбор правил** перед партией: победа до 121 / 61 / 50 очков или за 13 раундов,
  лоуболл, штраф за нулевой раунд, бонус за идеальную руку в 29 очков.
- **Сохранение после каждого хода.** Партия не пропадёт, если Android выгрузит
  приложение из памяти: состояние пишется в файл, случайные числа восстанавливаются
  из него же, поэтому соперник не начинает «сначала».
- **Вёрстка под Pixel 9 Pro XL** (2992 × 1344, то есть 336 × 748 dp) и под более
  низкие разрешения: всё считается в dp, ничего не зашито в пиксели.
- **Ноль внешних зависимостей** — только Kotlin stdlib и системные классы Android.
  APK получается около 500 КБ.

## Как собрать APK через GitHub

Ничего устанавливать на компьютер не нужно: Android Studio, Gradle и JDK не требуются.
Сборка целиком происходит на серверах GitHub.

### Шаг 1. Создайте репозиторий

На [github.com](https://github.com) нажмите **New repository**, назовите, например, `Cribbage`,
переведите переключатель в **Private** (можно и Public — сборка одинаковая), нажмите **Create**.

### Шаг 2. Загрузите файлы

Откройте репозиторий, нажмите **Add file → Upload files**, перетащите в окно
**всю папку проекта** (можно перетащить несколько файлов сразу, но папки
`.github`, `app` и `gradle` лучше загрузить через «Upload files» по одной —
браузер раскроет их структуру).

Либо из командной строки, если Git у вас есть:

```bash
cd C:\proj\Cribbage
git init
git add .
git commit -m "Криббедж: первая версия"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/Cribbage.git
git push -u origin main
```

### Шаг 3. Дождитесь сборки

Сборка запустится сама. Откройте вкладку **Actions** в репозитории — там будет
задача «Build APK» с зелёной галочкой, если всё прошло. Сборка занимает 3–5 минут
(в первый раз дольше — скачивается Gradle).

Если сборка упала, откройте её и посмотрите красную строку в логе — там будет написано,
в чём причина.

### Шаг 4. Заберите APK

Внизу страницы задачи есть раздел **Artifacts** со ссылкой **cribbage-apk**.
Скачайте — это будет zip-архив, внутри `app-debug.apk`.

### Шаг 5. Поставьте на телефон

1. Скопируйте `app-debug.apk` в телефон (кабель, Telegram, Google Drive — что угодно).
2. Откройте его в файловом менеджере.
3. Android спросит разрешение на установку из неизвестных источников — разрешите
   для того приложения, из которого открываете файл.
4. Установите и запустите.

## Как обновить игру

Внесите правки в файлы, залейте их в репозиторий (`git push`, либо перетащите
файлы в веб-интерфейс и нажмите Commit). Сборка запустится сама, новый APK
появится в Artifacts в течение нескольких минут. Старую версию удалять с телефона
перед установкой новой не нужно — Android обновит приложение сам.

## Структура проекта

```
app/src/main/java/com/mlaty/cribbage/
  MainActivity.kt     экраны: меню, правила, справка, цикл ходов компьютера
  model/Card.kt       карта
  model/Rules.kt      выбранные правила и уровень сложности
  game/Scoring.kt     подсчёт очков: 15, пары, серии, флеш, нобс
  game/Game.kt        состояние партии: сдача, к crib, розыгрыш, подсчёт
  game/Ai.kt          три уровня компьютера
  data/SaveStore.kt   сохранение и восстановление партии
  ui/GameView.kt      игровое поле, нарисованное на canvas
  ui/Theme.kt         палитра
.github/workflows/build-apk.yml   сборка APK
```

Подсчёт очков проверен по официальным примерам: 29 (идеальная рука 5-5-5-валет
при стартовой пятёрке), 24 (4-4-5-5-6), 24 (6-7-7-8-8), 12 и 6 для к crib.

## Если хотите подписать релизный ключ

Сборка выше отладочная, и её APK ставится на любой телефон без танцев с ключами.
Если понадобится релизная подпись, создайте ключ и добавьте в репозиторий
секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`,
после чего допишите в workflow шаг `signingConfigs`. Подробности — в официальной
документации Android Gradle Plugin по signing.
